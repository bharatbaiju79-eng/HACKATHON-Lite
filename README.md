# HACKATHON-Lite
Hackathon Lite – Coding Competition

This repository provides the structure and guidelines for Hackathon Lite, a school-level coding competition designed to test problem-solving and programming skills.

---

Overview

Hackathon Lite is a short-duration coding event where participants solve problems across multiple difficulty levels within a fixed time.

---

Competition Structure

The competition is divided into four sections:

- Section A – Basic (10 marks)
- Section B – Intermediate (30 marks)
- Section C – Advanced (30 marks)
- Section D – Challenge (30 marks)

Total Marks: 100

---

Objective

- Develop logical thinking
- Apply core programming concepts
- Solve problems efficiently under time constraints
- Write clean and structured code

---

Rules and Guidelines

- Allowed languages:
  C, C++, Python, Java
- Follow input and output formats strictly
- Ensure code is readable and well-structured
- Avoid unnecessary complexity

---

Evaluation Criteria

Submissions will be evaluated based on:

- Correctness of output
- Efficiency of the solution
- Code readability
- Problem-solving approach

---

Instructions

1. Attempt questions from all sections
2. Manage time effectively across difficulty levels
3. Test solutions with sample inputs before submission
4. Submit within the given time limit

---

Note

Participants are expected to show the code to the coordinators .
